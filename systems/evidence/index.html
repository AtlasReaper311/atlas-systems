How to read this evidence

Provenance boundary

A record can support a claim without proving the whole estate

Reads
One recorded public-safe change chain, one runtime Service View for a named Worker, a public topology Estate overview, plus public activity, raw availability, deployment, pipeline event, and assurance-report records.
Separates
ADR-0013 delivery stages, ADR-0014 profile applicability, classification lifecycle, observation result, claim, runtime state, evidence mode, supporting record, observation time, source time, and freshness. Classification is not delivery.
Freshness
Every source is judged independently. A merge is not a deployment. Runtime is not live. Topology is not an estate health badge. One fresh record cannot mask another stale, unknown, or unavailable source.
OBSERVED
Evidence was actually observed for this claim.
UNKNOWN / NOT OBSERVED
No approved evidence has established this claim.
FAILED
The evidence source or check was attempted and failed.
NOT APPLICABLE
This stage cannot exist for this subject or profile.

Opening Evidence Detail explains an existing record. It does not create stronger truth.
