How to read this evidence

Provenance boundary

A record can support a claim without proving the whole estate

Reads
One recorded public-safe change chain, a recorded Article Publication specimen for W-08, one runtime Service View for a named Worker, a public topology Estate overview with a recorded Library / Toolkit specimen for atlas-interface-kit, plus public activity, raw availability, deployment, pipeline event, and assurance-report records.
Separates
ADR-0013 delivery stages, ADR-0014 profile applicability, classification lifecycle, observation result, claim, runtime state, evidence mode, supporting record, observation time, source time, and freshness. Classification is not delivery.
Phase 2.3 archetypes
Static / Public Site, Runtime Worker, Library / Toolkit, and Article Publication share one ADR-0013 vocabulary. Domain labels are explanatory mappings, not a second lifecycle. Article Publication is inspectable in Change View because current public topology does not model published writing as an estate component. Model Promotion remains Phase 4 work.
Freshness
Every source is judged independently. A merge is not a deployment. Runtime is not live. Topology is not an estate health badge. One fresh record cannot mask another stale, unknown, or unavailable source.
