Model Promotion Observatory // Phase 4.5

Why this model.
For this capability.

Inspect two accepted public certification records for the same job. Start with the capability, compare only represented evidence, then follow evaluation, human review, and promotion as separate gates.

Open Evidence Console Systems directory

This Observatory is read-only evidence. It is not a global score, benchmark page, deployment dashboard, live runtime monitor, or model-control interface.

Certification boundary

Evidence is capability-specific

Compared
qwen3.5-mtp and qwen3:14b, only where both accepted public receipts exist.
Separated
Evaluation, human review, promotion, freshness, and deployment authority.
Excluded
Prompts, answers, private context, timing, runtime configuration, provider state, and live model identity.
