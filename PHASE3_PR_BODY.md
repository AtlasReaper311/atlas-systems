- add the five approved Lab routes to sitemap authority and generated output

- add regression coverage for indexing, navigation, maturity semantics, security contact, and performance evidence

## Validation

- repository HTML validation
- main-site, Lab, and System SYMPHONY tests
- sitemap regeneration and check-only validation

## Boundaries

This draft does not merge or deploy production. It does not change card iconography, social preview artwork, runtime APIs, Cloudflare settings, secrets, article publication, or blocking performance thresholds. Browser timing remains preview evidence; the committed baseline measures source-level first-party asset weight only.
