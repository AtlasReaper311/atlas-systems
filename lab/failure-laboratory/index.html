06 / RECOVERY

What can be truthfully said about recovery?

COMPOSITE ASSESSMENT

COMPOSITE ASSESSMENT / NOT AN OBSERVATION

Recovery has no single source of truth.

Different instruments can show reset, convergence, recorded aftermath, or a named lifecycle fact. Failure Trace keeps those signals separate until they support the same bounded conclusion.

BOUNDARY

Recovery-like output, aftermath, or a named lifecycle fact does not prove universal current service recovery or root-cause resolution.

Model-approved reading paths+

From dependency failure to recovery

  1. Request / Normal operation / Request X-Ray
  2. Dependencies / Dependency failure / CASCADE
  3. Dependencies / Cascading failure / CASCADE
  4. Incident evidence / Cascading failure / Blackbox
  5. Recovery / Recovery / CASCADE

Coordination and Impact remain omitted rather than inferred.

From bounded isolation to recovery

  1. Request / Normal operation / Request X-Ray
  2. Coordination / Network partition / Consensus
  3. Coordination / Network partition / Neon Relay
  4. Recovery / Recovery / Consensus

Dependencies, Impact, and Incident evidence remain omitted where the model has no bounded relationship.

Evidence modes+
Measured
Current source-owned measurement with source and observation time owned by the destination.
Stale measured
A previous measurement whose freshness threshold has elapsed.
Recorded replay
A named historical record. It is not current live state.
Simulated
Bounded synthetic behaviour created by an instrument.
Unavailable
Expected evidence cannot currently be retrieved or served.
Unknown
The available record does not establish the meaning or state.
Not applicable / unscored
The relationship is intentionally unsupported. No score is inferred.

Proof and interpretation rules+
  • A selected context is a guide only. It does not mean a real incident occurred.
  • Simulated behaviour is not production failure.
  • A topology relationship does not prove propagation.
  • Atlas Twin says only what could be affected, never what was affected.
  • Recorded replay is historical, not current live state.
  • Sonification is interpretation, not incident authority.
  • Source or merge state does not prove deployment, runtime, or live state.
  • Recovery-like output does not create one universal recovery authority.
