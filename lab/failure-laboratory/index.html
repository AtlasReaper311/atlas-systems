Model-approved reading paths

From dependency failure to recovery

A beginner-readable bounded path from a synthetic request baseline through dependency failure and propagation to an explicitly limited recovery reading.

  1. Request / Normal operation / Request X-Ray
  2. Dependencies / Dependency failure / CASCADE
  3. Dependencies / Cascading failure / CASCADE
  4. Incident evidence / Cascading failure / Blackbox
  5. Recovery / Recovery / CASCADE

Omitted stages: Coordination and Impact. The path does not invent evidence merely to fill the sequence.

From bounded isolation to recovery

A distributed-systems path using the closest bounded coordination and routing models, with its missing stages kept explicit.

  1. Request / Normal operation / Request X-Ray
  2. Coordination / Network partition / Consensus
  3. Coordination / Network partition / Neon Relay
  4. Recovery / Recovery / Consensus

Omitted stages: Dependencies, Impact, and Incident evidence. No current instrument supplies those stages for this bounded partition-oriented narrative.

These are model-approved explanatory paths, not synchronized execution traces. Each handoff still opens a separate instrument with its own state and evidence contract.

06 / EVIDENCE LANGUAGE

Read the label before the result.

The mode says what kind of evidence a destination can present. It does not make this route a live feed. For measured or recorded readings, source and freshness remain owned by the destination record.

Measured
A current source-owned measurement, with source and observation time shown by the destination.
Stale measured
A previous measurement whose freshness threshold has elapsed.
Recorded replay
A named historical record played back; it is not current live state.
Simulated
Bounded synthetic behaviour created by an instrument; it is not production failure.
Unavailable
Expected evidence cannot currently be retrieved or served.
Unknown
The meaning or state is not established by the available record.
Not applicable / unscored
This scenario/instrument relationship is intentionally unsupported; no score is inferred.

CARRY THESE BOUNDARIES BETWEEN ROOMS

The corridor does not close the unknowns.

  • A selected scenario is context only. It does not mean a real incident occurred.
  • Simulated behaviour is not production failure, and route availability does not prove the underlying scenario is live.
  • A topology relationship does not prove propagation.
  • Atlas Twin says only what could be affected; Twin is not incident evidence and never becomes “was affected” here.
  • Recorded replay is not current live state. Sonification is not automatically incident evidence.
  • Source or merge state does not prove deployment, runtime, or live state.
  • Recovery-like output does not create one universal Phase 3 Recovery Evidence authority.
