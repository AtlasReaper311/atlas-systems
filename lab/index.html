Reading the Lab

Commitment and data are separate.

A maturity label describes the interface contract. A data label describes what the experience is using now. Neither is a runtime-health claim.

Maturity

Production
Stable public product or surface.
Tool
Focused engineering utility.
Preview
Usable interface with a contract still being refined.
Experiment
Exploratory behaviour without a stable product contract.
Planned
Declared future work that is not yet a usable public surface.
Retired
Historical surface that is no longer an active public destination.

Data mode

Live
Current bounded public evidence.
Replay
Captured evidence played back.
Generated
Output produced in the browser or engine now.
Simulated
Explicit non-live scenario data.
