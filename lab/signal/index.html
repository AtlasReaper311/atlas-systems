Generative source memory

An evolving harmonic-noise source or a visitor-supplied local sample becomes the grain reservoir. Audio files are decoded in-browser and transferred once into the worklet without a server upload path.

Probabilistic harmonic genomes

Each ecosystem carries weighted pitch ratios and motion traits. Scale attraction defines harmonic gravity; tension progressively dissolves that gravity into microtonal instability instead of acting as a second quantize knob.

Living feedback field

Four prime-length delays use Hadamard mixing with moving read heads. Feedback weather, slow deterministic evolution, spectral transformation, and adaptive voice limits change the ecology while keeping the render path bounded.

Translation, not porting

The reusable concept is ownership. UI or gameplay code expresses low-rate intent. The audio renderer owns phase, envelopes, grain life cycles, source memory, spectral state, delay memory, and per-sample safety. In a browser that boundary is the worklet message port. In MetaSounds it is the graph input and operator boundary.

Deterministic seeds, explicit voice limits, and bounded modulation matter in both environments. The graph changes, but the real-time scheduling problem does not.
