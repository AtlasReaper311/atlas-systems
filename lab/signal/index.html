Source memory

An evolving harmonic-noise source is written into a four-second circular buffer. Grains read historical positions with fractional interpolation, so the processor synthesises its own material instead of replaying a bundled sample.

Granular scheduler

A seeded event accumulator creates overlapping Hann-windowed grains. Density, duration, transposition dispersion, gain, and pan remain bounded; the same seed and parameter path reproduce the same event sequence.

Feedback network

Four mutually coupled prime-length delays use a Hadamard mixing matrix. Feedback is capped below unity, followed by DC blocking and soft clipping. The structure can evolve without becoming an unstable browser siren.

Translation, not porting

The reusable concept is ownership. UI or gameplay code expresses intent at control rate. The audio renderer owns phase, envelopes, grain life cycles, delay memory, and per-sample safety. In a browser that boundary is the worklet message port. In MetaSounds it is the graph input and operator boundary.

Voice limits and deterministic seeds matter in both environments. A browser protects a visitor's CPU budget; a game protects the audio render budget across every active actor. The graph changes, but the scheduling problem is the same.
