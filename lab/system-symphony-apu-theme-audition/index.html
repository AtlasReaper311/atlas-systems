Listening guide

What should remain recognisable?

1. Learn Explorer

Start with Statement. Listen for the opening home note, the two-stage rise, the central high anchor, and the final return home.

2. Add pressure

Grid Pressure should retain those landmarks but arrive late, use shorter gates and stop short of a comfortable ending.

3. Compress the boss

Boss Protocol should reduce the same idea to root-and-fifth action cells. Weight should come from rhythm and articulation, not louder bass.

4. Lose the signal

Lost Signal should leave only distant landmarks and delayed echoes. It should feel incomplete, but not unrelated or empty.

5. Confirm recovery

Choose Recovery. The complete Explorer identity should return and finish at home, making the restoration audible.
