Listening guide

You only need to answer one thing at a time.

1. Hear Explorer

Use Explorer only until the tune feels familiar. Ignore the technology and listen for the overall rise and return.

2. Compare directly

Use the main comparison button. Explorer plays first, then the selected state after a clear pause.

3. Judge relation

Ask only whether the second phrase sounds descended from the first. It does not need to sound identical.

4. Ignore polish

No bass, drums, pads, arpeggios or effects are present. Those belong to later integration, not this identity test.

5. Trust confusion

If the connection is still unclear, the transformation is too aggressive or the reference melody is not memorable enough.
