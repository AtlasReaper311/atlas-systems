A useless instrument

It does not tell the time.

It records the difference between when this browser means to draw and when it actually does. Near misses stay amber. Longer hesitations leave pale seams and red scars.

Nothing is fetched. Nothing is inferred about the estate. The seed defines the machine; this tab supplies the weather. Close it and the weather is gone.

It does not finish.

Space / hold · N / new run · S / keep this frame

Focus the drawing or the page, then press Space to hold or continue, N for a new run, and S to save the current frame. The run state and seed update below the drawing without contacting the network.
