What EstateBoot shows.

This detailed sequence is the non-visual equivalent of the released media and remains available with JavaScript disabled.

  1. Public surface. The composition begins with atlas-systems.uk, the public portfolio and Lab surface.
  2. Public spine. It moves through atlas-api-public, the public API spine represented by the snapshot.
  3. Supporting components. The simplified view brings in status, atlas-blackbox, atlas-notify, and specular-telemetry.
  4. Infrastructure anchor. SPECULAR-CORE appears as the single infrastructure anchor derived from the telemetry declaration.
  5. Declared relationships. Six source-declared relationships resolve: atlas-systems → atlas-api-public, status → atlas-api-public, atlas-api-public → specular-telemetry, atlas-blackbox → specular-telemetry, atlas-blackbox → atlas-notify, and specular-telemetry → SPECULAR-CORE.
  6. Evidence close. The frame closes on the release and render identity: six components, one infrastructure anchor, and six relationships from the pinned snapshot.

Why this is deterministic release evidence

The Motion release binds the EstateBoot composition, the exact source commit, the pinned topology snapshot, and the output hashes. Atlas Systems vendors the resulting MP4 and poster as versioned static assets. It does not execute Motion, fetch the private Motion repository, or require a Motion API or provider at page load.

Evidence boundary

What this does not prove.

Release, render, and route evidence are deliberately kept separate from live-system evidence.

  • Current runtime health or current deployment state.
  • Current estate health or live topology freshness.
  • Current provider state or current production correctness.
  • Social or publication distribution beyond this separately verified Atlas Systems route.

The topology is historical/pinned, the media is a recorded replay, and this page is a public presentation of release evidence rather than a live Motion integration.
