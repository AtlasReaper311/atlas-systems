Isolate C, then write. A and B can still commit through quorum while C keeps an older local truth. Heal the link and watch C catch up before phase coherence returns.

This is a deliberately bounded teaching model, not Raft or Paxos. The leader stays fixed and link timings are deterministic so the interaction isolates proposal flow, quorum, stale replicas, partitions, and convergence.

Choose a commit policy and network profile, then press Write Next. Proposal packets leave replica A. Follower acknowledgements return to A. Quorum commits after two acknowledgements. Eventual exposes accepted state before every replica converges. Select a replica to inspect its local view.
