What this phase proves

Four composition grammars

Each state owns a scale, motif family, bass language, drum language, channel map and deterministic omission policy.

Intentional tension only

Diatonic notes remain inside the active F mode. Warning approaches, Critical alarms and Unknown drift are explicitly categorised and bounded.

Quantised transitions

State changes preserve transport position. Critical chokes old pad and counterline tails; Unknown dissolves over one bar.

Controlled dynamics

State-specific compression and RMS proxies create weight and space while the limiter ceiling remains fixed at -1 dB.
