# Atlas Motion v0.1.0 release media

This directory is an Atlas Systems-owned delivery copy of the `EstateBoot`
media from the exact Atlas Motion `v0.1.0` release.

- Source repository: `AtlasReaper311/atlas-motion`
- Source commit: `857f2a575480590c75186694a79860f60fcf899d`
- Composition: `EstateBoot`
- Asset and release hashes: `provenance.json`

The MP4 and poster are versioned, repository-local static assets. The page does
not fetch the private Motion repository, call a Motion API, or render from an
unversioned development build. The topology is a historical/pinned snapshot
and the media is a recorded replay; these files do not prove deployment,
runtime health, current estate health, provider state, live topology freshness,
production correctness, or wider publication distribution.

Rollback is the normal feature-branch rollback: remove this versioned asset
directory and the `/lab/atlas-motion/` route together, or restore the previous
Atlas Systems revision. Do not replace these files with a mutable upstream
download.
