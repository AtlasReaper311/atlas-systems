# Atlas Motion v0.2.0 EvidenceChain release media

This directory is an Atlas Systems-owned delivery copy of the exact
EvidenceChain media and engineering evidence from the published Atlas Motion
GitHub Release `v0.2.0`.

- Source repository: `AtlasReaper311/atlas-motion`
- Source commit: `ec9e5cdec34905e77ed0653b8a74372f79df2a8c`
- Composition: `EvidenceChain`
- Release manifest, render sidecar, FFprobe report, frame digest, reviewed
  input, and asset hashes: `provenance.json`

The GitHub Release is published, while the embedded release manifest records
`kind: candidate` and `tag_status: not-created`. Both facts are retained in
the local provenance so this page does not silently promote candidate-bundle
evidence into a stronger release claim.

The MP4 and stills are versioned, repository-local static assets. The page
does not fetch the private Motion repository, call a Motion API, render in the
browser, or claim a current rollout. EvidenceChain is a historical replay of
reviewed evidence-lifecycle vocabulary; its ordered stages do not prove that
any named stage occurred for a live subject.

Rollback is the normal feature-branch rollback: remove this versioned asset
directory and the EvidenceChain surface references together, or restore the
previous Atlas Systems revision. Do not replace these files with a mutable
upstream download.
