# Atlas Motion v0.3.0 TwinImpact release media

This directory is an Atlas Systems-owned delivery copy of the exact
TwinImpact media and release evidence from the published Atlas Motion GitHub
Release `v0.3.0`.

- Source repository: `AtlasReaper311/atlas-motion`
- Source tag: `v0.3.0`
- Source commit: `4894209b1fde44847e89a2c3f5dafa9d97153f16`
- Composition: `TwinImpact`
- Release manifest, Twin export, render sidecars, FFprobe report, frame
  digest, and asset hashes: `provenance.json`

The GitHub Release is published, while the embedded release manifest records
`kind: candidate` and `tag_status: not-created`. Both facts are retained in
the local provenance so this page does not promote the bundle into a stronger
release claim.

TwinImpact consumes a validated real Atlas Twin export for a proposed change
in `AtlasReaper311/atlas-api-public`. It presents Twin-supplied systems and
relationships that **COULD BE AFFECTED**. The relationship subset is a
deterministic presentation selection, not an importance ranking or a causal
claim. **NOT OBSERVED IMPACT.** The released evidence does not prove
deployment, runtime impact, provider state, current live state, current
service health, or current estate health.

The local evidence chain is:

`validated Atlas Twin export` → `Atlas Motion TwinImpact` → `v0.3.0 released evidence` → `repository-local public presentation`

The MP4, poster, input export, sidecars, and release manifest are versioned,
repository-local static assets. The page does not fetch an upstream Motion
repository, call a Motion API, render in the browser, or make provider,
runtime, or network calls.

Rollback is the normal feature-branch rollback: remove this versioned asset
directory and the TwinImpact surface references together, or restore the
previous Atlas Systems revision. Do not replace these files with a mutable
upstream download.
